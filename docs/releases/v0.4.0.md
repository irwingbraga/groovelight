## Highlights

- **Groovelight works with Claude.** Ask Claude Desktop or Claude Code to play, find, import and fix your music: "play Living Inside Myself by Gino Vannelli", "make a playlist of his ten best songs", "import the zip in my Downloads". Install the Claude Desktop extension attached below (`Groovelight-0.4.0.mcpb`) by opening it.
- **A command line tool.** `groovelight` drives the running app from Terminal and your scripts, with JSON output for everything.
- **Import archives.** Drop a zip, 7z, rar or tar on the window: it is extracted, identified and moved into your library, and the archive can go to the Trash.

## Claude and other AI assistants

Groovelight includes an MCP server (`groovelight mcp`), so AI assistants that speak MCP can use your library through 16 tools: search the library, play albums, artists, playlists and songs, control playback, see what is playing, create and fill playlists, import, fix metadata, organize file names, rescan and undo.

- **Claude Desktop:** download `Groovelight-0.4.0.mcpb` below and open it. The extension runs the server inside your installed Groovelight, so it stays in step with the app as it updates.
- **Claude Code:** put the tool in your PATH (below), then run `claude mcp add groovelight -- /usr/local/bin/groovelight mcp`.
- **Nothing changes without your yes.** Imports, metadata fixes and renames come as a preview first. Claude shows you what would change and applies exactly that preview, only after you agree. Imports and organizing can be undone.
- **Built to be safe with an AI.** No tool returns the contents of your files. Imports refuse private and system places (`~/Library`, hidden folders such as `~/.ssh`, your home folder as a whole), links inside archives are dropped, and the server talks only to the app on your Mac.
- **Answers stay current.** Results about what is playing, playlists and the library carry the time they were read, and Claude is told to ask again rather than rely on an old answer, since you keep using the app while you talk.

The full guide, with the tools, the safety model and troubleshooting, is in [docs/MCP.md](https://github.com/irwingbraga/groovelight/blob/main/docs/MCP.md).

## Command line

- `groovelight status`, `search`, `import`, `fix-metadata`, `organize`, `undo`, `rescan`, `play`, `pause`, `resume`, `next`, `previous`, `stop`, `now-playing`, `playlists`, `create-playlist` and `add-to-playlist`.
- Every command takes `--json`; `import`, `fix-metadata` and `organize` take `--dry-run`. Exit codes: 0 done, 1 failed, 64 a mistake in the command.
- The tool asks the app to do the work, so the library, undo and the windows stay in step. It starts Groovelight in the background when needed.
- To put it in your PATH, copy the command from Settings, General, Command Line and run it in Terminal.

The reference, with JSON shapes and scripting examples, is in [docs/CLI.md](https://github.com/irwingbraga/groovelight/blob/main/docs/CLI.md).

## Import

- Import zip, 7z, rar and tar archives (also `.tar.gz`, `.tgz`, `.tar.bz2`, `.tar.xz`) like songs and folders: drag them onto the window or use File, Import. They are extracted, identified on MusicBrainz and moved into your library.
- **Move archives to the Trash after importing**, an option in the import sheet. An archive goes only when everything from it was imported, and Undo Import puts it back.
- **Choose where imports go:** Settings, Library, Import into (useful with more than one music folder).
- Password-protected and multi-part archives are not supported yet.
