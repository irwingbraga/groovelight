## Highlights

- **Signed and notarized by Apple.** Groovelight is now signed with a Developer ID and notarized, so it opens with a normal double-click: no more "Open Anyway" in System Settings.

This release has the same features as 0.2.2: macOS 15 support, safer handling of external drives, Fix Metadata for mixed-up albums, Compilations in Artists, a faster Songs list and links in the player bar. See the [0.2.2 notes](https://github.com/irwingbraga/groovelight/releases/tag/v0.2.2) for the details.

## Updating from 0.2.x

- Earlier versions update themselves to this one.
- Because the app is now signed by a different identity, macOS may ask once to allow Groovelight to access its own data after the update. Allow it: your library, playlists and settings are all there.
- You may need to sign in to Last.fm again (Settings, Last.fm), since the saved sign-in belonged to the old signature.

## Installing

Download the DMG below, open it and drag Groovelight to Applications (macOS 15 or later).

The Android companion app, Groovelight Sync, is attached as an APK (Android 12 or later).
